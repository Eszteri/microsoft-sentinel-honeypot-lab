Microsoft Sentinel Honeypot Lab
Overview
This project documents the deployment and monitoring of a Windows honeypot using Microsoft Sentinel.

Technologies Used
Microsoft Sentinel
Azure Virtual Machines
Azure Monitor Agent (AMA)
Log Analytics Workspace
Windows Security Events
Sysmon
KQL (Kusto Query Language)
Objectives
Collect Windows security logs
Monitor failed and successful logins
Detect suspicious activity
Investigate security incidents
Perform threat hunting using KQL
